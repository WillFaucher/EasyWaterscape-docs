# Installation & Setup

## Add EasyWaterscape To Your Project

- Go to your library on FAB, find EasyWaterscape.
- Click on "Add to Project"
- Open the Unreal Engine project you have added EasyWaterscape to.
- You will find the EasyWaterscape folder in your project's content browser.

In **Unreal Engine 5.8**, when you add EasyWaterscape to your level, you might encounter the following pop up:  

![Project Settings Popup](/EasyWaterscape_Docs_AssetGuidelines_01.png)

This is only necessary to enable ***IF*** and ***ONLY IF*** you need to use the legacy [Disc Mesh](<Using EasyWaterscape/Water Mesh.md#mesh-mode>) approach.

Changing that project setting can affect how other water systems look. So it’s more of a last resort kind of thing.
