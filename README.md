This is the docs repo for EasyWaterscape, an FFT ocean system for Unreal Engine 5.

Run locally: `npm install`, then `npm run docs:dev` and open `http://localhost:5173`

Before/after image slider: put a line like this on its own in any page (images in `public/`):

```
[/BeforeAfter/Calm_Off.png|/BeforeAfter/Calm_On.png]
```
