# Playable Demo

Try EasyWaterscape before you buy. The free Windows demo lets you fly over the ocean, change the waves and foam live, switch between sea states, and run a built-in benchmark to see what the water costs on your own PC.

<p style="margin: 32px 0;">
  <a class="primary-button" href="https://github.com/WillFaucher/EasyWaterscape-demo/releases/latest/download/EasyWaterscapeDemo.zip">Try the Demo (Windows, 790 MB)</a>
</p>

::: info
The demo is a preview: only a selection of EasyWaterscape's settings are exposed, for the sake of not overcomplicating the UI. The full version on [Fab](https://www.fab.com/listings/ddd28113-6f59-4ba3-bf60-ad7b1920a547) provides far more control.
:::

## How to run
1. Extract the whole folder first; the demo won't run from inside the zip.
2. Run `EasyWaterscapeDEMO.exe`.

::: tip Windows protected your PC
Windows may show this warning because the demo isn't code-signed. Click **More info**, then **Run anyway**.
:::

## Requirements
- Windows 10 or 11 (64-bit)
- A DirectX 12 graphics card. Older cards switch to DirectX 11 automatically.

## What's in the demo
- Three sea states: Calm, Lake and Stormy
- Live controls for the waves, foam and performance settings
- A benchmark that measures the water's cost on your PC by comparing it against a flat plane

::: tip Lake Mode
You'll find that the Lake state is cut off in the shape of a rectangle, this is by design, and is done this way to showcase that you can limit the shape and size of EasyWaterscape.
:::
